# Website design specimens

Captured from the real local Worker preview with **sample data**, not a live kitchen or production deployment.

- `menu-desktop.png`: 1440px viewport, full page.
- `item-mobile.png`: 375px viewport, full page.

Real product images are absent in the sample catalogue, so the production image-fallback design is visible. The opening/offer state comes from sample data and the preview clock. Local font configuration includes system serif/sans fonts and Noto Sans Bengali for the taka glyph; those font files are not bundled or downloaded by the shipping website.

The headless browser run blocked third-party traffic. These captures do not prove Firebase authentication, map tiles/geolocation, placement of a real order, FCM delivery, or Android layout. The live preview is labelled **Redesigned storefront — sample data**.
